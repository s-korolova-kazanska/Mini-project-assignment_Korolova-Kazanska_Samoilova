### Процес аналізу
Для аналізу акцій ми використовували вбудовану бібліотеку yfinance. Для обробки та візуалізації даних ми використовували бібліотеки pandas та matplotlib.
Щоб розробити базову модель торгівлі на основі простої стратегії ми розрахували короткострокові і довгострокові ковзні середні на основі яких згенерували сигнали, які порівнюють їх. 
```
data["ShortMovAvg"] = data["Close"].rolling(7).mean()
data["LongMovAvg"] = data["Close"].rolling(28).mean()

data["Signal"] = 0
data.loc[data["ShortMovAvg"] > data["LongMovAvg"], "Signal"] = 1
```
Завдяки ним, ми визначаємо тренд, на основі якого ми вирішуємо купляти, утримати чи продавати.
